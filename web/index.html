ކީއްވެ DhiCode؟

ދިވެހި ބަހުން ޕްރޮގްރާމްކުރުމަށް ފަރުމާކުރެވިފައިވާ އެންމެ ފުރިހަމަ ވަޞީލަތްތައް

🇲🇻

ދިވެހި ބަހުގެ ފުރިހަމަ ތާނަ އަކުރުގެ ބާރު

ތާނަ އަކުރުތަކާއި، ފިލިތައް (Fili) އަދި ސުކުން ފަސޭހަކަމާއެކު ދެނެގަނެވޭނެހެން ލެކްސަރ އާއި ޕާސަރ ވަނީ ތައްޔާރުކުރެވިފައި. ފަރުމާ (Faruma) އަދި ފަސޭހަ (Faseyha) ފޮންޓުގައި ފުރިހަމައަށް އެޅޭނެ.

⚡

ދެ އިންޖީނުގެ ބާރު (Dual Engine)

ވަގުތުން ސްކްރިޕްޓް ހިންގާލުމަށް ޕައިތަން އިންޓަރޕްރެޓަރ، އަދި ހަލުވި ނޭޓިވް ބައިނަރީ (.o / .exe) އުފެއްދުމަށް އެލް.އެލް.ވީ.އެމް (LLVM) ބެކްއެންޑް.

📊

ލިސްޓާއި ރަދީފު (Lists & Dicts)

ލިސްޓު ހެދުމާއި، އިންޑެކްސް ކުރުން، އަޅާ() އަދި ނަގާ() ފަންކްޝަންތައް، ރަދީފު (Dictionary) އަދި ކޮންމެ (For-Each) ލޫޕް.

🛡️

ކުށް ސަލާމަތްކުރުން (Try/Catch)

ޕްރޮގްރާމް ނުހުއްޓި ކުރިއަށް ގެންދިއުމަށް މަސައްކަތްކުރޭ ... ކުށެއް_ފެނިއްޖެނަމަ ބްލޮކްތައް އަދި ތަފްޞީލީ ވިޝުއަލް ކުށުގެ ރިޕޯޓު.

🧩

ވީއެސް ކޯޑު އެކްސްޓެންޝަން (VS Code)

ކޯޑު ކުލަގަދަކޮށް ދައްކައިދޭ ސިންޓެކްސް ހައިލައިޓިންގ، އޮޓޯ-ކްލޯސިންގ ބްރެކެޓްތައް، އަދި އަވަހަށް ކޯޑު ލިޔުމަށް ޚާއްޞަ ސްނިޕެޓްތައް.

ކީވޯޑުތަކުގެ ގައިޑް

ދިވެހި ކޯޑުގައި ބޭނުންކުރާ މައިގަނޑު ބަސްތައް

ކީވޯޑު އިނގިރޭސި މާނަ ބާވަތް މިސާލު
ކަނޑައަޅާ let / define ވެރިއަބަލް ކަނޑައަޅާ އަގު = 50
ވަޒީފާ function ފަންކްޝަން ވަޒީފާ ހިސާބު() ... ނިމުނީ
ފޮނުވާ return ފަންކްޝަން ފޮނުވާ ނަތީޖާ
ދައްކާ print / output އައުޓްޕުޓް ދައްކާ "ސަލާމް"
ނަމަ if ޝަރުޠު ނަމަ އުމުރު > 18 ... ނިމުނީ
ނޫންނަމަ else ޝަރުޠު ނޫންނަމަ ... ނިމުނީ
ހިނދު while ލޫޕް ހިނދު ގުނާ <= 10 ... ނިމުނީ
ކޮންމެ for-each ލޫޕް ކޮންމެ އެތި ތެރޭގައި ލިސްޓު ... ނިމުނީ
މަސައްކަތްކުރޭ try ކުށް ސަލާމަތް މަސައްކަތްކުރޭ ... ކުށެއް_ފެނިއްޖެނަމަ
ގެނޭ import މޮޑިއުލް ގެނޭ "ހިސާބު"
އާން / ނޫން true / false ބޫލިއަން ކަނޑައަޅާ ތެދު = އާން
