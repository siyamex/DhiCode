ދެ ސިންޓެކްސް، އެއް ބާރު

ދިވެހި ތާނަ އަކުރުން ނުވަތަ އިނގިރޭސި ޓެކްނިކަލް ކީވޯޑުތަކުން ކޯޑު ލިޔުއްވާ! ދެ ބަސްވެސް ހިނގަނީ އެއް ހަމައެއްގައެވެ.

Symmetrical Dual-Language Engine

// SQLite Database in Thaana
ގެނޭ "ޑޭޓާބޭސް"
ކަނޑައަޅާ ޑީބީ = ހުޅުވާ("app.db")

ޑީބީ.ހިންގާ("CREATE TABLE users (id INT, name TEXT);")
ޑީބީ.ހިންގާ("INSERT INTO users VALUES (?, ?);", [1, "ޢަލީ"])

ކަނޑައަޅާ މީހުން = ޑީބީ.ހޯދާ("SELECT * FROM users;")

ޑީބީ.ލައްޕާ()
🌐 English Technical Syntax
// SQLite Database in English
import "db";
let db = open("app.db");

db.execute("CREATE TABLE users (id INT, name TEXT);");
db.execute("INSERT INTO users VALUES (?, ?);", [1, "Ali"]);

let users = db.query("SELECT * FROM users;");
print("Name:", users[0].name);
db.close();

🌐 English Technical Syntax
// OOP Classes & Inheritance
class Vehicle {
    fn constructor(name) {
        this.name = name;
    }
}

class Car extends Vehicle {
    fn drive() {
        return this.name + " is driving";
    }
}

let my_car = Car("Vehicle");
print(my_car.drive());

ކީއްވެ DhiCode؟

ދިވެހި ބަހުން ޒަމާނީ ސޮފްޓްވެއަރ ތައްޔާރުކުރުމަށް ފަރުމާކުރެވިފައިވާ ބާރުގަދަ ވަޞީލަތްތައް

🇲🇻

ދިވެހި ބަހުގެ ފުރިހަމަ ތާނަ އަކުރުގެ ބާރު

ތާނަ އަކުރުތަކާއި، ފިލިތައް (Fili) އަދި ސުކުން ފަސޭހަކަމާއެކު ދެނެގަނެވޭނެހެން ލެކްސަރ އާއި ޕާސަރ ވަނީ ތައްޔާރުކުރެވިފައި. ފަރުމާ (Faruma) އަދި ފަސޭހަ (Faseyha) ފޮންޓުގައި އަކުރު ނުގިރޭނެހެން ފަރުމާކުރެވިފައިވާ ސާފު ކޯޑިންގ.

🏛️

އޮބްޖެކްޓް-އޮރިއެންޓެޑް ޕްރޮގްރާމިންގ

ކްލާސްތައް (`class` / `ކްލާސް`)، ދަރިކޮޅު ނެގުން (`extends` / `ދަރިކޮޅު`)، ކޮންސްޓްރަކްޓަރު، މެތަޑްތައް އަދި `this` / `މި` ގެ ފުރިހަމަ އެހީތެރިކަން.

🗄️

އެމްބެޑެޑް އެސްކިއުއެލް ޑޭޓާބޭސް

އެއްވެސް ބޭރުގެ ޕެކޭޖަކާ ނުލައި ސީދާ އެސްކިއުއެލް (`db` / `ޑޭޓާބޭސް`) ހިންގުން. ޕެރާމީޓަރު ބައިންޑިންގ (`?`)، ޓްރާންސެކްޝަން ރޯލްބެކާއި ކޮމިޓް.

🚀

ނޭޓިވް އެޗްޓީޓީޕީ ސާވަރާއި ރައުޓަރ

ވެބް އޭޕީއައި (`net.serve` / `ސާވަރު`) ހެދުމާއި، މައިކްރޯ ރައުޓަރ، ކުއަރީ ޕެރާމީޓަރުތައް ކިޔުމާއި، ޖޭސަން އަދި އެޗްޓީއެމްއެލް ޖަވާބު ފޮނުވުން.

🌙

ދިވެހި ޘަޤާފީ ކޮމްޕިއުޓިންގ

27 ނަކަތް (`ނަކަތް`)، މޫސުމުގެ މަޢުލޫމާތު، ރާއްޖޭގެ ހުރިހާ އަތޮޅަކަށް ސީދާ ސޯލަރ ނަމާދު ވަގުތު (`ނަމާދު`)، އަދި އަދަދު ބަހަށް ބަދަލުކުރުމާއި ތާނަ ތަރުތީބު (`ތާނަ`).

🔒

ކްރިޕްޓޯގްރަފީ، ރެގެކްސް އަދި ފައިލް

SHA-256، SHA-512، HMAC، Base64، ޔުނިކޯޑު ރެގިއުލަރ އެކްސްޕްރެޝަންތައް (`ރެގެކްސް`) އަދި ފައިލް ކިޔުމާއި ލިޔުމުގެ ބިލްޓް-އިން ވަޞީލަތްތައް.

🎓 ދިވެހި ކޯޑު އެކަޑަމީން ޕްރޮގްރާމްކުރަން ދަސްކުރައްވާ!

ފިޔަވަޅަކުން ފިޔަވަޅަކަށް ދިވެހި ބަހުން ޕްރޮގްރާމިންގ ދަސްކޮށްދޭ އިންޓަރެކްޓިވް ކޯސް. ބްރައުޒަރ ތެރޭގައި ޗެލެންޖްތައް ފުރިހަމަކޮށް ވަގުތުން ސެޓްފިކޭޓް ހޯއްދަވާ!

🚀 އެކަޑަމީ ފައްޓަވާ

ކީވޯޑުތަކާއި މޮޑިއުލްތަކުގެ ގައިޑް

ދިވެހި ކޯޑުގައި ބޭނުންކުރާ މައިގަނޑު ބަސްތަކާއި ފަންކްޝަންތައް

ކީވޯޑު އިނގިރޭސި މާނަ ބާވަތް މިސާލު
ކަނޑައަޅާ let / define ވެރިއަބަލް ކަނޑައަޅާ އަގު = 50
ދާއިމީ const ދާއިމީ އަގު ދާއިމީ ޕައި = 3.14159
ވަޒީފާ fn / function ފަންކްޝަން ވަޒީފާ ގުނާ(x) ... ނިމުނީ
އަނބުރާ / ފޮނުވާ return ފަންކްޝަން އަނބުރާ ނަތީޖާ
ކްލާސް class އޮބްޖެކްޓް ކްލާސް ދަރިވަރު ... ނިމުނީ
ދަރިކޮޅު extends އޮބްޖެކްޓް ކްލާސް ޑޮކްޓަރު ދަރިކޮޅު އިންސާނާ
މި this / self އޮބްޖެކްޓް މި.ނަން = ނަން
ދައްކާ print / output އައުޓްޕުޓް ދައްކާ "ސަލާމް"
ނަމަ / ނޫންނަމަ if / else ޝަރުޠު ނަމަ އުމުރު > 18 ... ނިމުނީ
ހިނދު while ލޫޕް ހިނދު ގުނާ <= 10 ... ނިމުނީ
ކޮންމެ ... ތެރޭގައި for ... in ލޫޕް ކޮންމެ އެތި ތެރޭގައި ލިސްޓު ... ނިމުނީ
މަސައްކަތްކުރޭ try ކުށް ސަލާމަތް މަސައްކަތްކުރޭ ... ކުށެއް_ފެނިއްޖެނަމަ
ގެނޭ import މޮޑިއުލް ގެނޭ "ޑޭޓާބޭސް"
ހުޅުވާ open / connect ޑޭޓާބޭސް ކަނޑައަޅާ ޑީބީ = ހުޅުވާ("app.db")
ސާވަރު serve ނެޓްވޯކް ސާވަރު(8080, ރައުޓަރ)
މިއަދުގެ_ނަކަތް get_nakaiy ޘަޤާފަތް ކަނޑައަޅާ ނ = މިއަދުގެ_ނަކަތް()
މިއަދުގެ_ވަގުތު prayer_times ޘަޤާފަތް މިއަދުގެ_ވަގުތު("މާލެ")
އަދަދު_ބަހަށް num_to_words ތާނަ އަދަދު_ބަހަށް(125)
